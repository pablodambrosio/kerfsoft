# Kerfsoft 3D Viewer

A high-performance web solution to visualize and explore 3D models in your browser.

## Overview

Kerfsoft 3D Viewer enables interactive 3D model visualization directly in modern web browsers with support for multiple CAD, BIM, and 3D mesh formats.

## Supported File Formats

* **Import**: 3dm, 3ds, 3mf, amf, bim, brep, dae, fbx, fcstd, gltf, ifc, iges, step, stl, obj, off, ply, wrl.
* **Export**: 3dm, bim, gltf, obj, off, stl, ply.
