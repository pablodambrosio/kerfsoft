# Kerfsoft

Wood & Kerf Assembly CAD Platform built with React, TypeScript, Three.js, and Vite.

## Documentation

- [Kerfsoft File Specification (.kerf)](file:///c:/Projects/kerfsoft/app/doc/kerf-format.md): Specification document for `.kerf` JSON project files.

## Technical Stack

- **Framework**: React 19 + TypeScript + Vite
- **3D Graphics Engine**: Three.js (WebGL Extrude Geometry & Raycasting)
- **Local Storage**: Browser Native Storage Manager API
- **Linter**: Oxlint
